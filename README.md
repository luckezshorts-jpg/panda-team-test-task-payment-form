# Netaxept-style Test Payment Form

Static frontend-only QA mock.

- No backend
- No network requests
- No storage
- Visible TEST / SANDBOX marker

For validation, use only test data such as `4242 4242 4242 4242`, a future expiry date, and any 3–4 digit CVV.

Payment logos are bundled locally from https://github.com/aaronfagan/svg-credit-card-payment-icons (mono variant). Their license is included in assets/LICENSE.
